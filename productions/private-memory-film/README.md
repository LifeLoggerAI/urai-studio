# Private Memory Film Production Contract

This directory defines the reusable URAI Studio production boundary for a private, identity-consistent memory film.

## Privacy boundary

No client names, legal facts, service records, addresses, likeness media, private dialogue, analytics exports, or source evidence belong in this public repository.

Private scene data, identity references, source receipts, audio, and render artifacts must remain in the approved private Drive production vault or an equivalent access-controlled store.

## Production stages

1. Ingest approved identity, voice, scene, and evidence references.
2. Validate every factual claim against the private evidence ledger.
3. Build scene-specific motion packages with overlapping handles.
4. Capture canonical URAI Spatial routes at exact source authority.
5. Generate or film dialogue, body motion, environments, and transitions.
6. Compose picture, dialogue, ambience, effects, score, captions, and metadata.
7. Reject identity drift, synthetic dead-eye performance, sliding feet, broken hands, inconsistent tattoos, false geography, invented dialogue, and unverified claims.
8. Export private review masters, stems, captions, manifest, and hashes.
9. Require human acceptance before delivery.

## Non-negotiable rules

- No slideshow or still-image pan substitute for motion.
- No synthetic third-party voice without explicit permission.
- No fabricated reaction, testimony, endorsement, legal statement, or disputed-event reenactment.
- No passive-surveillance claim. Describe only pattern recognition across information the user knowingly supplied.
- The final direct-to-camera reveal must be genuinely recorded by the user unless explicitly approved otherwise.
- Never publish private counsel material from this pipeline.

## Required output

The renderer must produce a 4K cinematic master, 4K 16:9 counsel master, 1080p private review copy, stereo and 5.1 mixes, dialogue/music/effects/ambience stems, SRT, evidence ledger, shot manifest, QC report, and SHA-256 hashes.

See `render-contract.json` for the machine-readable gate.
