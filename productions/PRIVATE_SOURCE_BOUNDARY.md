# Private Source Boundary

This public repository does not contain private source media, private transcripts, family identity records, exact private locations, private cloud identifiers, or private production manifests.

Private production authority is maintained outside this public repository. Runtime integrations may reference that authority only through opaque, revocable references with provenance and consent enforcement.

Synthetic or cinematic output is derivative presentation material and can never become historical source truth.

Public release authorization remains separate from private production authorization and must be granted explicitly.
