**Trust invariant:** Hashes attest to a selection/plan only after genuine source content and owner rights are verified. A final movie must independently carry exact source object generations, SceneTruth, parent job, render plan, code/model/provider versions, audio/clip offsets, per-segment output checksums, license provenance, creation actor and revocation status. No reviewed current runtime proves all of these as one authenticated chain.
