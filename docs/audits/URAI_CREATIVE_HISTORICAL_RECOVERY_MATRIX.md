# URAI Creative Historical Recovery Matrix

Status: active recovery authority for the Studio creative-convergence lane.

This document records how historical URAI creative concepts map into the current system. It prevents old repositories, naming, prototypes and roadmap documents from silently becoming competing production authorities.

## Governing rule

Historical implementation is evidence of intent or prior work, not automatic launch authority.

Current production authority remains with the live owning systems:
- Storytime for story canon, narrator scripts, emotional arcs and relationship reflections;
- Studio for creative orchestration, directing, editing, score/motion direction, review and finishing;
- Jobs for governed render execution;
- Asset Factory for governed generated assets/provider execution/provenance;
- Spatial for approved immersive presentation;
- Privacy/Passport for consent and data-use authority.

## Integration rule

Recovered historical ideas are allowed into launch only through current owners and current contracts.

No historical code path may:
- bypass consent;
- bypass rights;
- activate provider spend;
- publish user media;
- weaken provenance;
- create duplicate rendering authority;
- create duplicate narrator authority;
- override current Spatial canon;
- inherit old visual or governance approvals.

## Evidence rule

Every recovered idea must ultimately resolve to one of:
- current implementation + current proof;
- current implementation awaiting proof;
- integrated historical semantics in a new current contract;
- explicitly superseded;
- external blocker;
- not legitimately launchable yet.

Do not leave recovered ideas in an ambiguous “future” bucket.
